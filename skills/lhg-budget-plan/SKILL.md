# lhg-budget-plan：预算科目规范与编制

> ## 声明（必读）
>
> 1. **以当年申报通知为准**：各资助机构的科目口径、比例上限（如间接费用比例、
>    劳务费上限）每年可能调整。本 skill 给的是**通用口径**，编制前务必核对
>    当年申报通知与预算编制说明，内容仅供参考。
> 2. **预算必须真实**：虚报、套取预算一经查实，后果严重。测算依据要经得起审计。

> 目标：编出一张"科目合规、测算有据、与研究内容对齐"的预算表。
> 核心纪律：**每笔钱三问——花在哪、为什么花、怎么算出来的**。

## 1. 何时使用

- 开始编预算表 → 全流程
- 预算被退回/被批"测算依据不足" → 直接第 4 步
- 不确定某个开支进哪个科目 → 直接第 2 步查表
- 预算和研究内容对不上 → 直接第 5 步

## 2. 输入与输出

**输入**：申请书研究内容（带"对应预算"标注）+ 资助机构当年预算编制说明。

**输出**：`application/07-budget.md` 预算表（科目/金额/测算依据三列）+ 对齐检查表。

## 3. 科目白名单与口径

| 科目 | 口径（能列什么） | 常见坑 |
|---|---|---|
| 设备费 | 购置/研制专用仪器设备 | 通用办公电脑一般不认 |
| 材料费 | 原材料、试剂、元器件 | 办公耗材别往里塞 |
| 测试化验加工费 | 委托测试、化验、加工 | 要有委托单位与单价依据 |
| 燃料动力费 | 水电油气（市内/实验用） | 别和差旅费混 |
| 差旅费 | 市外调研、开会差旅 | 市内交通不进这里 |
| 会议费 | 组织/参加学术会议 | 会议餐可含，招待餐不行 |
| 国际合作与交流费 | 国际合作、交流访问 | 要有合作方与计划 |
| 出版/文献/信息传播/知识产权事务费 | 版面费、文献检索、专利费 | 别简写成"资料费" |
| 劳务费 | 无编制人员的助研津贴 | 在读研究生走这里 |
| 专家咨询费 | 咨询、评审劳务 | 标准：院士/正高、其他分档 |
| 人员费 | 有编制人员的工资性支出 | 别和劳务费混 |
| 绩效支出 | 绩效奖励 | 有比例上限，看当年通知 |
| 间接费用/管理费 | 依托单位管理成本 | 按比例计提，不许列明细开支 |

## 4. 编制三原则

### 4.1 合理性：钱花在刀刃上

- 每笔开支都能回答"不花这笔钱，哪个研究内容做不下去"。
- 设备费占比 >50% 必须写必要性说明（否则像"买设备"不像"做研究"）。

### 4.2 必要性：与研究内容一一对应

- 画对应矩阵：研究内容一→设备费 X 万+材料费 Y 万；研究内容二→……
-  orphan 钱（找不到对应研究内容的开支）= 第一个被砍的。

### 4.3 可核查性：测算依据写到审计能复算

- 好写法：`GPU 服务器 1 台 × 20 万/台 = 20 万（附三家报价单）`。
- 坏写法：`设备费 20 万`。（依据呢？单价呢？数量呢？）
- 差旅：`北京调研 2 人 × 3 天 ×（交通 2000 + 住宿 800×3 + 补助 200×3）`。

## 5. 常见错配与退回原因 Top 8

1. **餐饮费/招待费**：不在科目内，直接退回。改：删掉或并入会议费。
2. **交通费**：口径不明。改：拆成差旅费（市外）/燃料动力费（市内）。
3. **工资/奖金**：表述不规范。改：人员费/劳务费/绩效支出三选一。
4. **资料费**：太笼统。改：拆成材料费/出版文献费。
5. **不可预见费**：多数机构不允许单列。改：删掉，分摊到各科目。
6. **缺测算依据**："一笔糊涂账"是退回重写的首要原因，每行都要有说明列。
7. **超限**：总额超过申报通知上限，或单项超过比例上限（如绩效支出）。
8. **与研究内容脱节**：2 个研究生 3 年，劳务费只列 5 万——评审会算账的。

## 6. 各科目编制要点详解

| 科目 | 编制要点 |
|---|---|
| 设备费 | 写清设备名称、型号档次、单价、数量、用途（对应哪个研究内容）；单价 ≥10 万的一般要附三家报价；已有设备不许重复购置 |
| 材料费 | 按"品名×单价×数量"列，单价要有来源（电商/供应商报价）；试剂耗材按年用量×年限算 |
| 测试化验加工费 | 写清委托单位、测试项目、单价、样品数；能自己做的别外包（评审会问） |
| 差旅费 | 按"目的地×人次×（交通+住宿×天数+补助×天数）"算；国际差旅单独说明必要性 |
| 会议费 | 主办会议：场租+专家食宿，按参会人数×天数算；只写"参加会议"进差旅费 |
| 劳务费 | 按"人数×标准×月数"算，标准参考依托单位规定；在读研究生、博士后走这里 |
| 专家咨询费 | 按"人次×标准"算，标准分档（院士/正高/其他），看当年通知 |
| 出版文献知识产权费 | 版面费按"篇数×单价"（OA 期刊单价高，提前查）；专利按"项数×代理费+官费" |
| 间接费用 | 按直接费用的一定比例计提（看当年通知），不许列明细开支 |
| 绩效支出 | 有比例上限，超了直接退回；先查当年通知再填数 |

**通用公式**：每行 = 品名/事项 × 单价 × 数量 × 依据来源。四个要素缺一个，
评审就多一个疑问。

## 7. 预算答辩常见问题（会评可能被问到）

1. **"设备费占比这么高，有必要吗？"** —— 提前准备一页必要性说明：
   哪个研究内容非它不可、为什么不能用已有设备/共享平台。
2. **"这个测算依据是什么？"** —— 每行都能报出"单价×数量+来源"，
   答不上来 = 预算可信度归零。
3. **"劳务费 12 万，2 个研究生 3 年够吗？"** —— 数字要和团队规模自洽，
   前后矛盾是硬伤。
4. **"为什么没有国际合作费/有国际合作费？"** —— 有合作写清对方与计划，
   没合作别硬凑，评审看得出来。
5. **"间接费用比例对吗？"** —— 按当年通知的比例，当场能算出来。

**准备原则**：预算表的每一行，都要能回答"为什么是这个数"。
答辩前把预算表打印出来，逐行自问一遍。

## 8. 反模式（不许这么干）

- **先定总额再凑科目**："先写 100 万，再想怎么花"——评审一眼看出是凑的。
- **科目名自创**："调研费""杂费""其他费用"——用白名单里的标准名。
- **测算依据写"市场价"**："市场价"三个字 = 没依据，给单价×数量+来源。
- **预算与内容两张皮**：申请书写一套，预算编另一套，对不上。
- **虚高/虚列**：红线，碰都别碰。

## 7. 自检与反馈

**质检门**：

- [ ] 所有科目都在白名单里吗（无自创科目名）？
- [ ] 每行都有测算依据（单价×数量+来源）吗？
- [ ] 总额 ≤ 申报上限吗？单项比例 ≤ 当年通知上限吗？
- [ ] 每笔钱都能找到对应的研究内容吗（对应矩阵画了吗）？
- [ ] 有合计行吗？数字加总正确吗？
- [ ] 当年申报通知的预算编制说明核对过了吗？
- [ ] 设备费占比 ≤50% 吗（超了有必要性说明吗）？
- [ ] 劳务费/人员费与团队规模自洽吗？
- [ ] 预算答辩 5 个常见问题都能答上来吗（见第 7 步）？

**标准冒烟用例**：用插件 `fixtures/grant-bad` 的预算表跑审计脚本，
确认 GT-BDG-001（科目错配）与 GT-BDG-002（超限）命中且退出码非零；
用 `fixtures/grant-good` 跑，确认零 blocker。

描述：资助机构、科目、拿不准的口径。
