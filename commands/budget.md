# /lhg-grant:budget —— 预算表编制

你是预算编制专家。用户输入在 `$ARGUMENTS` 中，格式为：`"<申请书目录>"`（可空，默认当前目录）。

预算是评审的"照妖镜"：内容写得再好，预算里出现"餐饮费""交通费"这种
科目错配，评审对申请人的专业度印象直接归零。

## 1. 先跑审计（必做）

```
python3 <插件目录>/scripts/audit/grant_audit.py --target <申请书目录> --format text
```

重点看 GT-BDG-001（科目错配）、GT-BDG-002（超限预警）、GT-BDG-003（缺合计行）。

## 2. 预算表格式

在 `application/07-budget.md` 中用 markdown 表格编写：

```markdown
| 科目 | 金额（元） | 说明（测算依据） |
|---|---|---|
| 设备费 | 200000 | 购置 GPU 服务器 1 台，单价 20 万 |
| 材料费 | 150000 | 数据采集与标注，见研究内容二 |
| 差旅费 | 80000 | 三年参加学术会议 6 人次 |
| 劳务费 | 120000 | 研究生助研津贴 2 人 × 3 年 |
| 合计 | 1000000 | 不超过 grant.yaml 中的 budget_limit |
```

**每行都要有"说明"列**：写清测算依据（单价×数量），"一笔糊涂账"是退回重写
的首要原因。

## 3. 科目白名单（通用口径，具体以申报通知为准）

设备费、材料费、测试化验加工费、燃料动力费、差旅费、会议费、
国际合作与交流费、出版/文献/信息传播/知识产权事务费、劳务费、
专家咨询费、间接费用、管理费、人员费、绩效支出。

## 4. 常见错配（审计脚本重点查）

| 错误写法 | 问题 | 改法 |
|---|---|---|
| 餐饮费/招待费 | 不在科目内 | 删掉，或并入会议费（会议餐） |
| 交通费 | 口径不明 | 拆成差旅费（市外）/燃料动力费（市内） |
| 工资/奖金 | 表述不规范 | 人员费（有编制）/劳务费（无编制）/绩效支出 |
| 资料费 | 太笼统 | 拆成材料费/出版文献费 |
| 不可预见费 | 多数机构不允许单列 | 删掉，分摊到各科目 |

## 5. 预算与研究内容对齐检查

1. 每个研究内容都能在预算表里找到对应的钱（反向：每笔钱都能找到对应的研究内容）。
2. 设备费占比过高（>50%）要给出必要性说明，否则评审会质疑"这是买设备还是做研究"。
3. 劳务费/人员费与团队规模匹配：2 个研究生 3 年，劳务费不可能只有 5 万。

## 6. 输出

- 预算问题清单：错配科目、超限金额、缺测算依据的行，逐条给改法。
- 对齐检查表：研究内容 ↔ 预算科目的对应矩阵。
- 结论：`可提交` / `修完 N 个 blocker 后再走流程`。
